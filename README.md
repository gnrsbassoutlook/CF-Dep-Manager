\# CF-Dep-Manager



\## 简介



CF-Dep-Manager 是一款面向 ComfyUI 便携版的\*\*可视化依赖管理工具\*\*，基于 Gradio 构建全中文图形界面，无需命令行操作即可完成 Python 依赖查看、安装、卸载，以及插件依赖反向查询、插件 GitHub 仓库快速跳转等功能，解决 ComfyUI 插件依赖排查繁琐、逐个打开 requirements 文件效率低的痛点。



\## ✨ 核心功能



\### 1. 系统依赖可视化管理



\- 一键读取当前 Python 环境所有已安装依赖，`Package` 左对齐、`Version` 右对齐，排版整齐易读

\- 支持一键导出完整依赖列表为 TXT 文件

\- 原生支持依赖包模糊搜索，输入关键词快速定位



\### 2. 图形化依赖安装 / 卸载



\- 选中依赖包即可一键安装 / 卸载，无需手动输入 pip 命令

\- 支持 `--no-deps` 选项，满足特殊安装场景

\- 实时显示执行日志，操作结果一目了然



\### 3. 插件依赖反向查询



\- 输入任意依赖包名，自动扫描所有插件的 `requirements.txt` 文件

\- 直接显示每个插件对该依赖的版本要求（如 `transformers==4.30.0`）

\- 无需逐个打开插件目录查看，高效排查依赖冲突



\### 4. 插件 GitHub 仓库识别与跳转



\- \*\*四重识别机制\*\*：`manifest.json` 字段、`\_\_init\_\_.py` 变量、`.git/config` 文件解析、Git 命令兜底，最大程度识别插件仓库地址

\- 全量插件 GitHub 地址列表，支持名称模糊搜索过滤

\- 点击链接直接在新标签页打开插件 GitHub 主页，解决启动器内地址无法点击的痛点

\- 自动统计插件总数、已关联 GitHub 数量、未识别数量



\### 5. 插件 requirements 文件在线查看



\- 下拉选择任意插件的 requirements 相关文件，界面内直接显示完整内容

\- 选中文件自动显示对应插件的 GitHub 跳转链接

\- 支持重新扫描插件目录，新增插件即时更新



\### 6. 紧凑全中文界面



\- 全中文标签与提示，无学习成本

\- 布局紧凑优化，充分利用页面空间，无冗余留白



\## 📦 安装与运行



\### 环境要求



\- Windows 系统（适配 ComfyUI 便携版目录结构）

\- Python 环境（ComfyUI 自带的便携 Python 即可）

\- ComfyUI 插件目录（默认路径 `ComfyUI/custom\_nodes`）



\### 启动步骤



1\. 下载或克隆本项目到本地任意目录

2\. （可选）编辑 `CF-Dep-Manager.py`，修改顶部默认的 Python 目录和插件目录为本地实际路径

3\. 双击 `launch.bat` 启动工具，浏览器会自动打开管理界面

4\. 点击右上角「刷新全部」加载所有数据即可使用



\## 📖 使用说明



\### 顶部操作栏



\- \*\*Python 目录\*\*：设置 ComfyUI 便携版的 Python 根目录

\- \*\*插件目录\*\*：设置 ComfyUI 插件存放目录（通常为 `ComfyUI/custom\_nodes`）

\- \*\*刷新全部\*\*：重新读取系统依赖、扫描插件目录、更新 GitHub 地址列表



\### 系统依赖列表



\- 左侧展示当前环境所有已安装的 Python 包及版本号

\- 点击「导出为 TXT」可将完整列表保存到本地



\### 依赖搜索与操作



1\. 在「选择 / 搜索依赖包」下拉框输入关键词，自动过滤匹配的依赖

2\. 选中后自动显示当前已安装版本

3\. 勾选「不安装依赖 (--no-deps)」可跳过子依赖安装

4\. 点击「安装」或「卸载」执行对应操作，底部显示执行日志



\### 插件反向查询



\- 选中依赖包后，自动列出所有包含该依赖的插件文件及对应版本要求

\- 选中插件文件后，左侧自动显示该 requirements 文件的完整内容



\### 插件 requirements 文件详情



\- 下拉选择任意插件的 requirements 文件，查看完整内容

\- 文件内容上方显示对应插件的 GitHub 主页链接，点击直达

\- 点击「重新扫描」更新插件文件列表



\### 插件 GitHub 仓库一览



\- 展示所有识别到 GitHub 地址的插件列表，点击名称直接跳转仓库

\- 顶部显示插件总数、已关联数量、未识别数量统计

\- 搜索框输入关键词可快速过滤匹配的插件



\## 🔧 自定义配置



\### 修改启动端口



打开 `CF-Dep-Manager.py`，拉到最底部，修改 `server\_port` 参数：



```

if \_\_name\_\_ == "\_\_main\_\_":

&#x20;   demo.launch(

&#x20;       server\_name="127.0.0.1",

&#x20;       server\_port=8186,  # 修改为目标端口号

&#x20;       inbrowser=True

&#x20;   )

```



\### 修改默认路径



在界面顶部输入框直接修改即可；如需设置永久默认值，编辑代码中对应输入框的 `value` 字段即可。

\## 💡 补充说明



\- 本工具原生适配 Windows 平台 ComfyUI 便携版，Linux/macOS 可自行调整路径格式使用

\- 未识别到 GitHub 地址的插件，多为压缩包安装、二次修改或无公开仓库的插件，属于正常情况

\- 安装 / 卸载依赖建议在关闭 ComfyUI 后操作，避免文件占用导致执行失败
